# 🛒 Compras da Semana

Uma aplicação web para organizar as compras da semana de forma simples, intuitiva e visualmente agradável. Desenvolvida com **HTML, CSS e JavaScript puro**, a aplicação permite gerenciar itens, acompanhar o progresso das compras e manter os dados salvos no navegador.

O projeto foi desenvolvido a partir de um desafio da **Rocketseat** e expandido com funcionalidades adicionais para aprimorar a experiência do usuário e praticar conceitos de desenvolvimento web.

## ✨ Funcionalidades

- ➕ **Adicionar itens:** inclua novos produtos à lista.
- ✅ **Marcar como concluído:** acompanhe os produtos que já foram comprados.
- 🗑️ **Remover itens:** exclua produtos individualmente.
- 📊 **Painel de estatísticas:** visualize o total de itens, pendentes e concluídos.
- 📈 **Barra de progresso:** acompanhe visualmente o andamento das compras.
- 🔎 **Pesquisa de itens:** encontre produtos rapidamente.
- 🗂️ **Filtros inteligentes:** visualize todos os itens, apenas os pendentes ou os concluídos.
- 🧹 **Limpar concluídos:** remova de uma só vez os itens já comprados.
- 💾 **Armazenamento local:** mantenha a lista salva no navegador usando `localStorage`.
- 🌙 **Modo escuro:** alterne entre os temas claro e escuro.
- 🔔 **Notificações visuais:** receba mensagens após realizar ações.
- 📱 **Layout responsivo:** utilize a aplicação em computadores, tablets e celulares.
- 📅 **Data atual:** visualize a data no cabeçalho da aplicação.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização, responsividade, animações e temas.
- **JavaScript:** manipulação do DOM, eventos, filtros e gerenciamento dos itens.
- **LocalStorage:** persistência dos dados no navegador.
